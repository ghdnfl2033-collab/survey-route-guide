# 실태조사 길잡이

국유재산 실태조사 담당 직원이 **엑셀 필지 목록만 올리면**, 자차·대중교통·도보별로 **총 소요 시간이 가장 짧은 방문 순서**를 계산해 지도와 표로 보여 주고 엑셀로 내려받게 해 주는 웹앱입니다.

방문 순서를 개인의 감에 맡기던 일을 줄여, 계획 수립 시간(약 30분 → 5분 이내)과 하루 이동 거리를 줄이는 것이 목표입니다.

## 주요 기능

**핵심 (must)**
- 엑셀(.xlsx / .csv) 올리기: 첫 시트 첫 열(지번 주소)만 읽고, 같은 주소는 하나로 합침
- 주소 → 위치 찾기, 못 찾은 필지는 "확인 필요"로 두고 지도에서 직접 찍기
- 동선에 넣을 필지 고르기 (최대 30필지)
- 자차 / 대중교통 / 도보별 최적 방문 순서 계산 (조사 시간 포함, 출발지 복귀 또는 마지막 필지 종료 선택)
- 지도 경로선과 순서표, 대중교통은 환승 횟수와 이용 노선(승차·하차 정류장), 엑셀 내려받기
- 길찾기 실패 시 직선거리로 계산하고 "추정값" 표시, 차량 접근이 어려운 필지는 "도로 끝에서 도보 이동 필요" 표시

**편의 기능 (nice)**
- 조사 결과 기록(완료·이용 현황·메모)과 엑셀 저장, 필지 묶음 저장, 출발지 기록·즐겨찾기
- 인쇄용 화면, 순서 직접 바꾸기, 여러 날로 나누기, 날씨 확인
- 결과표 주소를 눌러 카카오맵 길찾기 열기, 지도/스카이뷰 전환

## 기술 스택

- Next.js 16 (App Router) · React 19 · TypeScript · Tailwind CSS 4
- 지도·길찾기·대중교통: 카카오맵 / 날씨: 공공데이터포털 기상청 단기예보
- 배포: Vercel

## 개인정보·보안

- 엑셀은 브라우저에서 읽고, 위치 찾기에 필요한 주소만 서버로 보냅니다. 서버는 저장하지 않습니다.
- 조사 결과·올린 목록은 서버에 저장하지 않습니다. 필지 묶음과 출발지 즐겨찾기만 사용자 브라우저에 저장합니다.
- 로그인 대신 직원끼리 공유하는 접속 코드 하나로 입장합니다.
- API 키는 서버 코드에서만 쓰고, 지도 표시용 JavaScript 키만 브라우저에 들어갑니다(카카오 개발자 설정에서 사이트 주소 제한).

## 실행 방법

```bash
npm install
cp .env.example .env   # 값을 채웁니다
npm run dev            # http://localhost:3000
```

| 명령 | 설명 |
|---|---|
| `npm run dev` | 개발 서버 |
| `npm run build` | 빌드 |
| `npm run lint` | 린트 |
| `npm test` | 테스트 |

필요한 환경 변수 이름은 [.env.example](.env.example)에 있습니다. 실제 값은 `.env`(또는 Vercel 환경 변수)에만 넣고 저장소에 올리지 않습니다.
